# Workflow : génération ou retouche d'image maîtrisée

Skills : game-art-router → image-generation-direction → art-direction → (skill du sujet) → visual-quality-review.

1. **Outil** : un générateur est-il disponible dans la session ? Sinon, produire un prompt prêt à coller
   (Canva, Midjourney…) et le dire. Ne jamais annoncer une image non produite.
2. **Brief** (squelette du skill) avec invariants et variations permises ; une fonction par référence.
3. **Explorer** largement les seuls choix ouverts (composition, silhouette).
4. **Figer** la direction ; **une variable à la fois**.
5. **Inspecter** chaque image retenue : mains, pieds, membres, nombre d'objets, perspective, texte, accessoires,
   détails culturels (rien d'inventé présenté comme vrai).
6. **Corriger** par retouche ciblée, paint-over, vectoriel ou 3D pour les détails de production.
7. **Tracer** : prompt, outil/version, graine, références, image retenue, corrections.
8. **Revue** et passation.

Image→3D (Tripo, Meshy) : un seul objet entier, centré, fond uni, lumière douce sans ombre portée, vue 3/4,
sans texte (voir `docs/modeles_sur_mesure.md`), puis workflow `modele-3d-blender.md`.
