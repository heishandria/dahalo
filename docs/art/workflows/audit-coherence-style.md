# Workflow : audit de cohérence de style

Skills : game-art-router → art-direction → colour-light-and-materials → visual-quality-review.

1. Rassembler les assets approuvés (bible §9) et le nouvel asset ; captures **en jeu** à la même caméra.
2. Comparer : complexité de silhouette, proportions, bords, palette, plage de valeurs, matériaux, lumière,
   densité de détails, échelle relative.
3. Classer chaque écart : zone de style voulue / dérive accidentelle.
4. Corriger les dérives ; écrire la règle manquante dans la bible, avec un contre-exemple.
5. Mettre à jour la planche de calibration (un personnage, un objet, un élément de décor).
6. Tester la règle avec un second agent/modèle sur le même brief ; ne garder que les règles qui améliorent
   réellement la cohérence.
